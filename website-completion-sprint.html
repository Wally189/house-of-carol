Website Completion Sprint

Finish the website you already have.

Your website may be mostly built but still not properly finished.

The pages are there, but some still need work. Navigation or calls to action are inconsistent. The mobile version has awkward sections. A form or contact route has never been properly tested. Final content is waiting to be added. Release settings are unclear. Or the website has simply become a list of small jobs that nobody is owning from end to end.

You may not need another redesign. You may need someone to finish what is already there.

House of Carol takes one existing website that is substantially built and worth preserving, works out exactly what is preventing it from being properly complete, fixes the agreed final-mile issues and tests the resulting site against a clear completion standard.

What the sprint does

We start by establishing the actual current state of the agreed website — what is complete, unfinished, broken, uncertain or waiting on you.

We then separate the work needed to make the agreed site genuinely release-ready from later improvements, new features and redesign ideas.

Within the agreed scope, we complete the final-mile work, test the exact candidate, correct in-scope defects and leave you with a clear release decision.

What you get

For one existing website:

A takeover/completion map showing what is complete, partial, defective, uncertain or customer-dependent.

One agreed MUST-FIX completion scope, with later improvements and new ideas kept separate.

Completion of the agreed page-content placement/light editing, navigation, headings, calls to action, internal links and layout/responsive corrections.

Verification of the agreed enquiry/contact route where it is available and authorised for testing.

Basic release hygiene across the in-scope pages, including obvious broken routes, page titles/descriptions and indexing/release state where relevant.

Proportionate mobile, keyboard, readability and basic accessibility checks.

Exact pre-release QA against ordinary, awkward and failure cases.

Correction and retesting of one bounded cycle of in-scope defects.

A handover showing whether the agreed site is RELEASE READY, what remains held and who owns each remaining item.

If controlled deployment is part of the agreed job, the exact release action still requires explicit customer authority. Where deployment is not included or authorised, the sprint stops at RELEASE READY.

What we need from you

One accountable person who can make website decisions.

The current website URL and platform/codebase/CMS details.

The minimum legitimate access needed for the agreed work.

The brand, content and assets that must be retained.

Any customer-owned legal, privacy, cookie or terms content that the site must carry, or the appropriate owner for those materials.

Timely decisions where a completion blocker depends on you.

Please do not send passwords, authentication codes, recovery information, private keys or unnecessary confidential information by ordinary email or message. Where access is required, we agree the safest practical route first.

Good fit

This sprint is designed for an owner-managed or small service organisation when:

  • the website already exists and is substantially built;
  • the current platform, theme or codebase is supported and worth preserving;
  • the remaining problem is a mixture of final page, journey, responsive, contact-route, release or QA work rather than one trivial fix;
  • one accountable person can make the remaining decisions;
  • the organisation wants a defined finish line rather than an open-ended redesign project.
Probably not a good fit

If all you need is one or two simple fixes or a quick audit, a £1,250 completion sprint is probably more than you need. We would rather tell you that than turn a small job into a consulting project.

It is not the right standard service when you need:

  • a brand-new website;
  • a full rebrand or unrestricted redesign;
  • ecommerce, payment processing, a portal, membership system or bespoke web application;
  • a major migration or replatform;
  • complex integrations;
  • hosting, domain or vendor procurement;
  • extensive copywriting, photography or asset production;
  • ongoing SEO, content marketing or long-term website management;
  • penetration testing or legal, privacy, security or accessibility certification.

If finishing the current website would be poor value compared with rebuilding it, House of Carol should say so rather than stretching the sprint to fit.

Why pay for this instead of a quick fix or website audit?

Because the intended product is not a report listing problems and it is not a bundle of disconnected small fixes.

The value proposition is end-to-end ownership of the final mile: establish what is genuinely unfinished, agree the boundary, preserve what is already good, complete the bounded work, coordinate the blockers, test the exact candidate, correct defects and leave a truthful release decision.

If that level of ownership is not what you need, this is probably not the right service.

How it works

1. Qualify

Establish whether the existing site is suitable for completion rather than rebuild.

2. Map

Inspect the agreed pages and identify what is complete, defective, uncertain or waiting on you.

3. Define

Lock the exact completion scope, exclusions, responsibilities and finish line before consequential work begins.

4. Complete

Make only the agreed final-mile changes while preserving valid existing work.

5. Test

QA the exact candidate across links, navigation, contact route where testable, mobile/responsive behaviour, relevant accessibility basics and failure cases.

6. Correct

Fix in-scope defects and retest.

7. Hand over

Return a clear release-readiness state and the remaining owners/dependencies.

8. Release

Only where deployment is included and the exact release action is explicitly authorised.
