Services

Start with the problem. Keep the work bounded.

House of Carol is commissioning two practical B2B services. Each begins with a defined result, clear exclusions and a testable finish rather than an open-ended consultancy promise.

01 · Flagship

Workflow implementation

One awkward operational process, simplified and improved without buying complexity first.

We look at what actually happens now: the trigger, steps, decisions, hand-offs, documents and tools. We remove avoidable duplication and confusion before proposing technology, then implement the smallest agreed improvement and test it.

Good fit
A recurring process that already exists and is repeatedly slow, unclear, duplicated, error-prone or unreliable.
You receive
Current-state findings, an agreed better workflow, the bounded implemented improvement where authorised, test evidence and a clear handover.
Approach
Existing tools first. Automation only when it genuinely improves the result.
Boundary
Not open-ended transformation, ongoing process ownership, a large software build or regulated professional advice.
Support
Clarification and one correction/retest of an in-scope defect within the agreed post-delivery window.

02

Website release assurance

A practical independent check before a small website or major update reaches customers.

We review the agreed pages and primary journey in the agreed test environments, looking for release defects in navigation, links, mobile presentation, usability, content, basic accessibility, release-oriented SEO and obvious public-surface privacy or security issues. Findings are evidence-led and prioritised.

Good fit
Small teams, founders and agencies approaching website launch, redesign release or client handover.
Standard boundary
Up to 10 agreed public pages/templates and one primary user journey for the commissioning package.
You receive
A prioritised findings report with location, evidence, severity, why it matters, recommended action and a bounded retest.
Test coverage
The quote states the actual browser/device environments checked; comprehensive cross-browser or device certification is not implied.
Boundary
Not penetration testing, formal WCAG certification, legal accessibility opinion, full performance/load testing or fixing the defects unless separately agreed.

If the sensible answer is “do less”, that is still a useful answer.
